# Version 1.0
## 模块整合  
电机模块与交互模块整合
该版本主要目的为通过语音控制电机旋转
暂未涉及到nlu部分（nlu识别精确度有待提高

## Module Integration
This version integrates the motor control module with the interaction module.  
The primary goal is to enable voice-controlled motor rotation.  
The NLU component is not yet fully integrated, as the recognition accuracy still requires further improvement.
