# 树莓派5安装使用与代码日常维护
## 安装工具相关
tool:     Raspberry Pi Imager
system:   Raspberry Pi OS (64-bit)
wifi:     same as your pc
Services: SSH (远程连接很重要！)

插入U盘或者用读卡器读取SD卡，烧入linux环境，完成后电脑无法读取U盘相关信息，为正常现象

在获得一个有linux环境的U盘或者SD卡后，将其插入树莓派中并接电，此时树莓派会自动连接上配置好的wifi网络（具体表现为绿灯亮起）

## 远程连接相关
### cmd配置远程连接
1.确保环境正确 ：ping (hostname).local  
2.远程连接树莓派 ssh username@hostname.local 或 ssh username@IP
IP为确保环境正确步骤中显示的ip地址

tips:成功后会提示输入密码，在cmd窗口中输入密码时密码不会显示，直接盲打后回车确认
连接成功后会显示username@hostname:xxx
连接过程中会提示一堆文字，不用管直接点输入yes

### 在vscode中配置ssh远程连接
首先确认扩展程序中成功下载Remote-SSH
左下角会出现一个大于小于符号组合在一起的符号，为ssh远程连接
点击，上方点击连接至主机，添加新的主机，然后输入在cmd中输入过的相同的指令，例如ssh username@IP,后续步骤与cmd连接类似

### 基础配件安装
以管理员身份运行树莓派相关工具，且升级
sudo apt update && sudo apt upgrade -y
安装cmake，git，gdb调试组件
sudo apt install build-essential cmake git gdb libgpiod-dev gpiod -y

## git认证相关
### 配置git认证
git config --global user.name "Your Name"
git config --global user.email "your_student_email@glasgow.ac.uk"
### 密匙配置，防止每次git提交输入密码
创建密匙 : ssh-keygen -t ed25519 -C "GitHub邮箱"
输入后一直回车直到出现图案
获取密匙 : cat ~/.ssh/id_ed25519.pub
返回 (ssh-ed25519 xxxxxxx email)
复制这段内容到git设置中，点击SSH and GPG keys,添加SSH keys
*验证链接 : ssh -T git@github.com

## 树莓派相关：
### 硬件相关
长按开关：强制关机
单次点击：开机
短按：关机
### 指令相关
cmd关机：sudo shutdown now
cmd重启：sudo reboot
多wifi备份： sudo nmtui 提前将收集热点进行备份，以免需要重新烧入环境（回到first step）
实时温度查看：vcgencmd measure_temp
硬盘空间查看：df -h
