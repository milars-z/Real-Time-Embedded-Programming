# 3D Printing Integration

## Overview
This folder contains documentation for the 3D printing and hardware integration part of our real-time embedded programming project.

## Responsibility
Responsible team member: Dingyan Guo

My contribution includes:
- selecting a suitable open-source 3D model
- preparing the model for printing
- printing the required parts
- testing fitting and assembly
- documenting the hardware integration process

## Important Note
The robot arm model used in this project is based on the open-source **EEZYbotARM Mk2** project.
It is not claimed as original CAD work by our team.
Please see `SOURCE.md` for attribution details.
